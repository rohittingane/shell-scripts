# 🐧 Shell Scripts

A collection of Bash scripts created during my DevOps learning journey.

These scripts demonstrate Linux automation, system monitoring, backup management, file handling, and troubleshooting.

---

## 📂 Scripts Collection

| Script | Purpose |
|---|---|
| healthcheck.sh | Checks system health |
| healthloop.sh | Continuous monitoring script |
| backup.sh | Creates backup files |
| multibackup.sh | Handles multiple backups |
| safebackup.sh | Performs safe backups |
| log_rotate.sh | Automates log rotation |
| deploycheck.sh | Deployment validation |
| input_validation.sh | Validates user input |
| sample_logs_generator.sh | Generates sample logs |
| scriptaudit.sh | Audits shell scripts |
